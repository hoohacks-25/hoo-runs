# HooRuns
HooRuns is a web application designed to find routes whereever you are using AI, specifically Gemini. Whether you're looking for a quick jog or a long run, HooRuns provides curated routes to help you explore the area with confidence. HooRuns was built for the 2025 HooHacks hackathon
## Features
 - Curated Running Routes: Discover a variety of running routes around UVA and Charlottesville, suitable for different distances and difficulty levels.
 - Interactive Map: Visualize routes on an interactive map to easily see the path, start/end points, and key landmarks.
 - User-Friendly Interface: A clean and intuitive interface makes it easy to browse, select, and view route details.
## Tech Stack
- Frontend: React, Vite
- Backend: Express, Gemini
- Styling: Tailwind CSS
